# Support

## Before asking for help

Please check:

- The latest [README.md](README.md)
- [CHANGELOG.md](CHANGELOG.md)
- Existing GitHub Issues
- Recent commits

## Bug reports

Open a GitHub issue and include:

- Browser and version
- Device / OS where relevant
- Exact steps to reproduce
- Expected behavior
- Actual behavior
- Console error (if any)
- Screenshot when useful

**Never** post passwords, API keys, private client data, or confidential case information.

## Feature requests

Explain:

- The problem you are trying to solve
- The proposed solution
- Why it is useful
- Any compatibility or data-migration concerns

See also the **Planned** section in [CHANGELOG.md](CHANGELOG.md).
