# Code of Conduct

## Our standard

We are committed to a respectful, constructive, and professional project environment.

Participants are expected to:

- Be respectful and considerate.
- Discuss ideas and code, not people.
- Accept constructive feedback.
- Avoid harassment, insults, discrimination, and personal attacks.
- Keep project discussions focused and useful.
- Never post private client data, credentials, or confidential case information in issues or PRs.

## Scope

This Code of Conduct applies within project spaces (issues, pull requests, discussions) and in any public space when an individual is representing the project.

## Enforcement

Project maintainers may remove, edit, or reject contributions and discussions that violate this code of conduct.

For serious or repeated issues, contact the project maintainer privately (repository owner: [0utLawzz](https://github.com/0utLawzz)).
